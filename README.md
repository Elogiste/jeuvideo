#  FestiFruits

**FestiFruits** est un jeu vidéo scolaire développé en **C# avec Unity**, combinant **deux mini-jeux complémentaires** dans un univers original autour du personnage principal **Titou**. Le jeu mêle **plateforme 2D** et **aventure 3D de survie**, offrant une double expérience ludique et immersive.

---

##  À propos du jeu

###  Mini-jeu 1 — *FestiFruits 2D* : Platformer

Dans ce mode, Titou doit :

- Évoluer dans un monde coloré en 2D
- Ramasser **toutes les oranges** pour rester en bonne santé 
- **Tuer tous les ennemis**
- **Éviter les pièges**
- **Terminer le niveau avec au moins 1/3 de ses vies**, sous peine de tout recommencer

>  Ce mini-jeu permet d’introduire le personnage dans un gameplay accessible, rapide et dynamique.

---

###  Mini-jeu 2 — *SurviTerra 3D* : Aventure / Survie

Dans cette seconde phase, **Titou se retrouve transformé en humain** et projeté dans un univers parallèle, où il doit :

- Se **vêtir** pour se protéger du froid
- Se **nourrir** et **s’hydrater** pour survivre
- Explorer la nature sauvage
- **Combattre des ours** féroces 
- Survivre aussi longtemps que possible

>  Ce second jeu approfondit le gameplay avec une dimension stratégique et immersive en 3D.
